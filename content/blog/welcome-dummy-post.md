This is a **placeholder blog post**. It only exists to demonstrate the blog
listing and the individual post layout.

To publish a real post: create a file in `content/blog/` (for example
`content/blog/how-i-reduced-defects.md`), fill in the front matter, and write the
body in Markdown. It appears in the listing automatically, newest first.

## Markdown works as you'd expect

- Bulleted and numbered lists
- **Bold**, _italic_, and [links](https://example.com)
- Inline `code` and fenced code blocks:

```python
def hello(name: str) -> str:
    return f"Hello, {name}"
```

Set `draft: true` in the front matter to hide a post from the build until it's
ready.
